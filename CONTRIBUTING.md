# Contributing to Sahakar Seva

Thank you for contributing to Sahakar Seva!

## Development Workflow

We use a feature-branch workflow.

### 1. Create a branch

Create your branch from `development`.

Use the following naming convention:

- `feature/<feature-name>` — New feature
- `fix/<issue-name>` — Bug fix
- `docs/<topic>` — Documentation changes

Example:

`feature/customer-home`

### 2. Make your changes

Work only on the task assigned to you.

Keep your changes focused and avoid modifying unrelated files.

### 3. Commit your changes

Write clear commit messages.

Example:

`feat: add customer home page`

### 4. Push your branch

Push your branch to the Sahakar Seva repository.

### 5. Create a Pull Request

Create a Pull Request targeting:

`development`

Do not directly push to `main`.

### 6. Code Review

At least one team member should review the Pull Request before merging.

### 7. Merge

After approval and successful checks, the Pull Request can be merged.

## Branch Structure

```text
main
  └── Stable / production-ready code

development

feature/*
